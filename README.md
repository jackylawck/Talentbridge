# 🌐 TalentBridge SH-HK (滬港賢智匯) 
### Enterprise Cross-Border HR AI Governance Engine

本儲存庫為**2026年數據要素×滬港合作開放數據競賽**專案《滬港賢智匯》之核心技術開源版本。專為跨國企業設計，旨在解決 AI 人才決策系統中的數據隱私、算法黑箱與跨境傳輸合規痛點。

## 🚀 核心特性 (Core Features)
- **零信任隱私防護**：內建中港兩地專屬 Regex 引擎，自動脫敏高風險 PII (HKID, 內地身份證)。
- **自動化風險遙測**：基於 ISO 42001 標準，提供董事會級別的 AI 系統風險評估 (AIIA)。
- **管治即代碼 (Governance-as-Code)**：將 PDPO 與 PIPL 合規要求轉化為可執行的 Python 腳本。

## 🏗️ 快速啟動
```bash
# 執行 AI 治理引擎
python src/governance_engine.py

```
